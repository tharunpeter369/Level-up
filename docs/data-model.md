# Data Model and API

Moved from sections 6 and 7 of `skillforge-project-plan.md`. This file is now the source of truth. The Drizzle schema in code must match it; update this file in the same change as any schema change.

## Conventions

- Table names: plural `snake_case`. Columns: `snake_case`.
- Primary keys: `uuid` (generated by Postgres, `gen_random_uuid()`), except join tables (composite keys).
- Every table has `created_at timestamptz not null default now()`; mutable tables also have `updated_at`.
- All timestamps are `timestamptz` in UTC. Day-based logic (streaks, quests) uses the user's `timezone`.
- Foreign keys always have an index.

## Key API endpoints (starting set)

| Method and path                 | Purpose                                                    | Phase |
| ------------------------------- | ---------------------------------------------------------- | ----- |
| `GET /health`                   | Liveness check                                             | 0     |
| `GET /auth/github` and callback | Login with GitHub                                          | 1     |
| `POST /auth/logout`             | End session                                                | 1     |
| `GET /syllabus`                 | Module and topic tree with your progress                   | 1     |
| `PATCH /topics/:id/progress`    | Update status                                              | 1     |
| `POST /problems/:id/attempts`   | Log an attempt (emits `ProblemSolved`)                     | 1     |
| `GET /me/dashboard`             | Dashboard data                                             | 1     |
| `GET /reviews/due`              | Today's review queue                                       | 2     |
| `POST /reviews/:cardId`         | Submit a rating (updates FSRS state, emits `CardReviewed`) | 2     |
| `GET /me/quests`                | Daily quests                                               | 2     |
| `POST /ai/hint`                 | Hint ladder (SSE)                                          | 4     |
| `POST /ai/review-code`          | AI code review                                             | 4     |
| `POST /ai/cards`                | Generate draft cards for approval                          | 4     |
| `GET /me/skill-tree`            | Skill tree                                                 | 5     |
| `GET /search?q=`                | Typeahead over topics, problems, notes                     | 6     |
| `POST /ask`                     | "Ask my notes" (SSE)                                       | 6     |
